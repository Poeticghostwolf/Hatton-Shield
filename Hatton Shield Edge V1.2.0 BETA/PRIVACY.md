# Privacy

Hatton Shield performs filtering locally inside the browser. It does not use analytics, telemetry, a remote AI classifier, cloud uploads, or an account system.

Supported page text, captions, labels, hashtags, links, and bounded metadata are inspected in memory for local filtering decisions. This includes Discord Web/Twitch/social content when those adapters are enabled. Hatton Shield does not persist raw browsing history, chat/message history, social-feed history, screenshots, or classifier traces.

The optional known-AI-site guard stores a temporary per-tab allowance in extension-owned in-memory session storage.
